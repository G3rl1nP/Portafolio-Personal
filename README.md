## 🧩 Proyectos

### 🏛️ Sistema de Biblioteca (PostgreSQL)

Diseño y construcción de una base de datos relacional para la gestión de una
biblioteca: autores, libros, usuarios y préstamos.

**Incluye:**
- **Diagrama Entidad-Relación (E-R)** de las entidades y sus relaciones.
- **Creación de tablas (DDL)** con claves primarias, claves foráneas y restricciones.
- **Datos de ejemplo (DML)** mediante `INSERT`.
- **Consultas SQL** usando `JOIN` para relacionar tablas.

**Tecnologías:** PostgreSQL · SQL · pgAdmin

---

## 🚀 Cómo ejecutar

1. Abre el archivo `biblioteca.sql` en pgAdmin.
2. Ejecuta el script en el orden indicado (creación → datos → consulta).
3. Revisa los resultados con las consultas de ejemplo incluidas.
